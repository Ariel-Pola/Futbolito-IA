# Futbolito IA

Videojuego tipo futbolito desarrollado con Unity y C#, en el que el jugador se enfrenta a un equipo controlado por un agente de inteligencia artificial entrenado mediante Unity ML-Agents.

## Descripcion

Futbolito IA es un proyecto de residencia profesional desarrollado en equipo.

El objetivo del proyecto fue desarrollar un videojuego tipo futbolito en el que un jugador humano pudiera enfrentarse a un equipo controlado por inteligencia artificial.

El videojuego cuenta con un agente de IA entrenado mediante aprendizaje por refuerzo utilizando Unity ML-Agents.

## Tecnologias

- Unity
- C#
- Unity ML-Agents
- Python
- Anaconda
- mlagents-learn

## Caracteristicas

- Partidos de futbolito contra un equipo controlado por IA.
- Agente de inteligencia artificial entrenado mediante aprendizaje por refuerzo.
- Menu principal.
- Sistema de marcador.
- Fisica e interaccion de los elementos del juego.
- Entrenamiento y evaluacion del agente de IA.

## Inteligencia Artificial

El proyecto utiliza Unity ML-Agents para entrenar un agente mediante aprendizaje por refuerzo.

Durante el desarrollo participe principalmente en la optimizacion del entrenamiento existente, realizando ajustes en diferentes variables y parametros con el objetivo de mejorar el comportamiento y desempeño del agente.

El entrenamiento fue realizado utilizando `mlagents-learn` y un entorno de Anaconda.
